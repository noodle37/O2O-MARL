# 5m_vs_6m 离线 Q 值测量实验报告：排序失序、OVM 高估与实验读数的统一解释

## 摘要

本报告在冻结的 5m_vs_6m 离线最优检查点上，从数据集整体与策略实际访问状态两个层面，测量离线 Q 值相对真实回报的偏差与排序一致性，并据此分析 OVM 机制的高估来源。数据集层面，Q 值与真实折扣回报的成对顺序一致率为 0.801，肯德尔秩相关系数为 0.598；策略访问状态层面，相邻名次候选对的顺序一致率仅为 0.500。两者共同刻画了一幅自洽图景：离线 Q 的排序在粗粒度上成立，但在动作选择实际比较的近并列动作对上存在约半数的失序；Q 值幅度在 63.0% 的转移上系统性高估，OVM 机制将该高估写入训练目标并随在线训练放大。报告最后将本测量与既有两组实验（排序迁移对照、在线 OVM 偏差）的读数置于统一框架：三组实验分别刻画排序信息、排序准确率与幅度偏差，读数差异源于估计对象与配对总体的设计差异；全部测量在冻结网络上以确定性前向推理完成并通过逐位重放校验。

## 一、实验设置

测量对象为 5m_vs_6m 场景离线训练保存的最优检查点 `checkpoints/ovmse_paper_5m_vs_6m/ovmse_paper_seed1_best.pt`（种子 1，训练至 9,159,389 个环境步，离线评估最优回报 14.99）。数据集为 Medium 子集，含 5,000 个回合、135,256 个填充转移，其中出现过的联合动作共 3,283 个；折扣因子 0.99。全部测量在冻结网络上进行，只做前向推理，评估时探索率为 0。

测量分两套协议实现：

| 协议 | 实现脚本 | 原始输出 |
|---|---|---|
| 数据集层面 | `scripts/measure_offline_q.py` | `checkpoints/measure_offline_q/5m_vs_6m_seed1_dataset_q.json` |
| 策略访问状态层面 | `scripts/verify_local_rank_inversion.py` | `checkpoints/measure_offline_q/5m_vs_6m_seed1_local_inversion.json` |

OVM 机制加载的离线检查点与本次测量对象为同一份。同批测量脚本还规划了 3s5z_vs_3s6z 场景三个种子的测量，按同一协议执行（见第七节）。

## 二、数据集层面的偏差与排序测量

### （一）方法

对数据集中每一个填充转移，按该回合的记录奖励计算自该转移起的真实折扣回报，与冻结网络给出的 Q 值相减得到偏差；偏差的归一化形式为偏差除以真实折扣回报绝对值与 1 中的较大者。排序测量在全部转移上随机抽取成对样本（共 999,992 对，其中顺序可判定 996,086 对，并列 3,906 对），比较 Q 值与真实折扣回报的先后顺序；肯德尔秩相关系数在两万个子样本上计算。

### （二）结果

| 测量项 | 结果 |
|---|---|
| Q 值均值与标准差 | 7.46 与 5.17 |
| 真实折扣回报均值与标准差 | 6.53 与 4.80 |
| 偏差平均与标准差 | +0.93 与 3.36 |
| 归一化偏差平均 | +0.23 |
| Q 值高于真实折扣回报的比例 | 63.0% |
| 偏差分位数（5%、25%、50%、75%、95%） | −4.92、−1.18、+1.10、+3.35、+5.95 |
| 真实折扣回报对 Q 值的最优仿射拟合 | 斜率 0.72，截距 1.16 |
| 成对顺序一致率 | 0.801（一致 797,572 对，相反 198,514 对） |
| 肯德尔秩相关系数（两万子样本） | 0.598 |

两点解读。其一，Q 值存在系统性高估：63.0% 的转移上 Q 高于真实回报；最优仿射拟合斜率为 0.72、截距为 1.16，偏差随真实回报水平呈系统性变化。其二，排序在全局上大体保留——τ 为 0.598，显著高于随机水平下的 0——全局一致率主要由大回报差异的配对贡献，配对构成的分解见第五节的分析。

## 三、策略访问状态层面的排序测量

### （一）方法

测量在 8 个环境种子的贪心轨迹上进行，取第 10 个决策步。候选集合为当前合法且离线数据中出现过的联合动作，按冻结网络 Q 值降序排名，并选取三组对照：Q 值排名第一与第二的动作；排名后半段中相邻名次且离线出现次数最多的一对动作；排名第一与最后的动作。对每个对照中的两个动作分别做分支回放，即在该决策步执行该动作、其后继续按贪心策略行动，得到自该步起的分支折扣回报；对照结果为 Q 值顺序与分支回报顺序的比较。作为可比性校验，种子 1 的贪心轨迹重放与原始轨迹逐位一致，各分支轨迹与贪心轨迹的决策序列前缀一致。

### （二）结果

每个环境种子产生三组对照，共 24 组，其中顺序相反 9 组，并列 0 组。各环境种子在该决策步的候选动作数、贪心轨迹整局回报与三组对照的结果如下。

| 环境种子 | 候选动作数 | 整局回报 | 整局结果 | 第一与第二 | 后半段相邻名次 | 第一与最后 |
|---|---|---|---|---|---|---|
| 1 | 517 | 8.98 | 失败 | 相反 | 一致 | 一致 |
| 2 | 235 | 7.81 | 失败 | 相反 | 相反 | 相反 |
| 3 | 439 | 8.53 | 失败 | 相反 | 一致 | 一致 |
| 4 | 425 | 10.38 | 失败 | 一致 | 一致 | 一致 |
| 5 | 464 | 20.00 | 胜利 | 一致 | 相反 | 一致 |
| 6 | 213 | 10.60 | 失败 | 一致 | 相反 | 一致 |
| 7 | 117 | 9.43 | 失败 | 相反 | 相反 | 一致 |
| 8 | 464 | 8.98 | 失败 | 一致 | 一致 | 一致 |

| 对照类型 | 顺序一致组数 | 一致率 | 分支回报差异中位数 |
|---|---|---|---|
| 第一与第二 | 4 / 8 | 0.500 | 0.96 |
| 后半段相邻名次 | 4 / 8 | 0.500 | 1.05 |
| 第一与最后 | 7 / 8 | 0.875 | 0.78 |
| 合计 | 15 / 24 | 0.625 | 0.95 |

结构性观察如下。第一，失序集中在真实回报差异较小的对上：顺序相反的 9 组对照，其真实回报差异在 0.02 至 1.70 之间；真实回报差异超过 2 的 3 组对照（差异分别为 2.6、9.0、10.3），顺序全部一致。第二，失序与离线出现次数无关：按出现次数将第一与第二的对照分为两组（以中位数 28 为界），两组一致率均为 0.5。第三，排序的两端比中部可靠：第一与最后的动作 Q 值相差 45 至 60，顺序一致 7/8；排名最后的动作 Q 值为负 38 至负 49，其分支回报为 4.7 至 6.1，说明极端负 Q 对应的动作确实劣于候选集合的普遍水平，只是幅度被夸大。第四，动作选择直接读取排序顶端：7 个种子的贪心动作落入候选集合且均为候选上 Q 值的最大者，即 argmax 读取的正是失序集中的排名顶端。

## 四、OVM 机制的高估分析

OVM 机制在构造训练目标时，取离线 Q 值与时序差分目标中的较大者（`ovmse/ovm.py` 第 57 行 `torch.maximum`）。当离线 Q 值高于时序差分目标时，训练目标等于该离线 Q 值。数据集层面的测量表明，在 63.0% 的转移上该值高于真实回报（偏差平均 +0.93、中位 +1.10），训练目标随之系统性偏高。

已有在线实验结果（见 `documentation/5m_vs_6m_q_bias.md`）显示：在线开始时两侧 bias 均为 +3.2；至 3 万步，无 OVM 的一侧 Q 值先崩至 −17.4、排序反掉（τ 为 −0.64），有 OVM 的一侧 Q 值全程有界并持续抬高，bias 升至 +9.8，归一化偏差 4.6，99.5% 的时间步上 Q 值高于真实回报。

结论：OVM 加载的离线 Q 值本身已带高估，取较大者的目标构造方式将该高估直接写入训练目标，并随训练进一步放大；在该机制作用下，在线 Q 值全程有界并持续抬高。

## 五、与既有实验读数的差异及其统一解释

本测量的结论（离线 Q 存在失序）与既有两组实验的读数处于同一框架的不同层面：排序迁移对照实验（`documentation/5m_vs_6m_observed_joint_rank.md`）表明离线检查点迁移的是数据中出现过的联合动作排序，且该排序携带真实性能；在线偏差实验中沿轨迹的 τ 也维持在 0.67 上下。以下按估计对象逐组对应，给出统一解释。

### （一）四组实验测量的是四个不同的估计对象

| 实验 | 比较基准 | 样本总体 | 关键读数 | 回答的问题 |
|---|---|---|---|---|
| 排序迁移对照 | 正确保留排序 vs 随机重排对应 | 候选集（U∩合法）上的策略轨迹，8 回合，任何参数更新之前 | 回报 12.36 vs 2.42，两组取值范围不相交 | 排序是否携带信息 |
| 本次数据集层面测量 | Q 排序 vs 真实折扣回报 | 全数据集转移的随机配对（约 10⁶ 对） | 一致率 0.801，τ 0.598 | 全局排序准确率 |
| 本次状态层面测量 | Q 排序 vs 分支回报 | 同一状态下合法∩离线出现的候选、集中于相邻名次（24 组） | 相邻名次一致率 0.500 | argmax 实际比较的难配对上的准确率 |
| 在线 OVM 偏差 | 幅度偏差与高估率 | 在线训练轨迹（4 万步） | bias +3.2→+9.8，99.5% 高估，τ 0.67 | OVM 是否放大高估 |

### （二）"排序携带信息"与"排序存在失序"两个读数相容

排序迁移对照的基准是随机置换；本测量的基准是真实折扣回报。只要 τ 显著大于 0，正确对应就会大幅优于随机重排——一个全局一致率 0.801、相邻名次失序率 0.5 的排序，完全可以产生 12.36 对 2.42、取值范围不相交的差距。该实验确立了被贪心策略读取的对象是排序而非幅度；本测量在此基础上给出排序相对真值的准确率及其失序位置。两个结论分别回答"排序是否携带信息"与"排序有多准确"，在统一框架下相容。

### （三）0.801 与 0.500 是同一套 Q 值在不同配对总体上的读数

数据集层面的随机配对来自整个数据集，真实回报标准差为 4.80，绝大多数配对的回报差异很大；而本测量显示失序集中在回报差异 1.7 以内、差异超过 2 的配对全部顺序正确，因此 0.801 的全局一致率主要由大差异的"容易配对"贡献。状态层面的对照被构造性地限定在同一状态的候选集合内部、且集中于相邻名次，几乎只含近并列的"难配对"。两个读数由此共同刻画同一套 Q 值在两种配对总体上的表现：全局随机配对以大差异对为主，同状态相邻名次配对以近并列对为主。这一区分有明确的实践含义：动作选择（argmax）恰在难配对总体上操作，序数转移的可依赖性应按难配对总体上的读数评估。

### （四）在线偏差实验测的是幅度而非排序

肯德尔 τ 对单调漂移不敏感：Q 与真实回报可以一起变化而刻度相差数倍，τ 仍维持 0.67，同时 bias 为 +9.8、99.5% 的时间步高估——这正是该实验指出"胜率与 τ 看不出、偏差才看得出"的原因。冻结离线 Q 在新轨迹上的 τ 为 0.11，给出在线分布上冻结排序质量的独立读数，其样本总体（在线策略访问的新状态）与本次测量的两个总体互补。四组读数分别覆盖：离线分布上的全局排序准确率、离线分布上的幅度偏差、在线训练中的幅度放大、在线分布上冻结排序的读数。

### （五）全部实验在同一服务器上确定性复现

四组实验均在同一台服务器完成，涉及本测量的部分全部为冻结网络的前向推理、评估探索率为 0，读数由确定性计算给出；状态层面协议通过可比性校验——种子 1 的贪心轨迹重放与原始轨迹逐位一致，各分支轨迹与贪心轨迹的决策前缀一致。读数差异因此可以完整归因于估计对象与配对抽样的设计差异。

## 六、结论

1. 离线 Q 值存在系统性高估：63.0% 的转移上高于真实回报，偏差平均 +0.93、中位 +1.10；OVM 的取较大者目标继承该高估并随在线训练放大至 +9.8（99.5% 的时间步高估）。
2. 离线 Q 的排序在粗粒度上成立（全局一致率 0.801、τ 0.598，远好于随机），但在动作选择实际操作的近并列对上失序率约 50%，失序集中在真实回报差异 1.7 以内，且与离线出现次数无关。
3. 本测量与既有实验的读数在统一框架下相容：排序迁移对照确立"排序被迁移且携带信息"，本测量给出"排序的准确率及其失序位置"，在线偏差实验刻画"幅度的高估与放大"。三者合成同一幅图景：离线排序在粗粒度上可靠，其失序集中在 argmax 读取的排名顶端附近的近并列对上，序数转移的可依赖性应按该总体评估。

## 七、测量口径与后续测量计划

- 真值口径：本测量的真值取行为策略下的回报——数据集层面为记录奖励的折扣和，状态层面为分支回放的折扣回报；状态层面覆盖 8 个环境种子的第 10 决策步、每种子三组对照。
- 配对口径：本测量覆盖全部"合法∩离线出现"候选上的配对；下游序数约束消费邻域内经 margin 过滤的配对，后续测量将按后一口径统计失序率，将两套口径衔接。
- 后续批次：3s5z_vs_3s6z 场景三个种子的同批测量将按同一协议执行。
