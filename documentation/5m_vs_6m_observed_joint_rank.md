# 5m_vs_6m：离线检查点迁移的是数据中出现过的联合动作排序

要验证的命题是：离线检查点中能够被贪心策略使用的，不是联合动作价值的数值，而是离线数据里真正出现过的联合动作之间的排序。

比较在任何参数更新之前完成。在线时序差分更新开始之后，网络可以重新学出一套排序，那时的回报差不再表示离线检查点里保存的是什么。

## 设置

环境是星际争霸多智能体挑战中的 5m_vs_6m。离线数据为 Medium 子集，共 135256 个转移。每个智能体有 12 个离散动作，联合动作空间的大小为 \(12^{5}=248832\)。其中至少出现过一次的联合动作有 3283 个，记为支持集 \(\mathcal{U}\)。

检查点是离线训练保存的 `checkpoints/ovmse_paper_5m_vs_6m/ovmse_paper_seed1_best.pt`。网络是单调值分解：各智能体的动作价值经单调混合网络得到联合动作价值 \(Q_{\mathrm{tot}}\)。混合网络单调，所以全体合法联合动作上的最大值点，等于各智能体分别对自己的动作价值取最大。因此，只要这个贪心联合动作属于 \(\mathcal{U}\)，它也是 \(\mathcal{U}\) 与当前合法动作之交上的最大值点。

评估时探索率为 0，不更新参数。两条规则从同一个环境随机种子出发，各评估 8 个回合。每一步的候选集，是 \(\mathcal{U}\) 里当前每个智能体都可以执行的联合动作。

- 保留排序：在候选集上选取 \(Q_{\mathrm{tot}}\) 最大的联合动作。
- 重排对应：这组 \(Q_{\mathrm{tot}}\) 的取值作为多重集合保持不变，随机重新分配给候选集中的联合动作，再取最大。两条规则的差别只在数值与联合动作的对应关系。

候选集若为空，则执行网络自身的贪心联合动作。本次评估中候选集没有为空。

贪心联合动作是否落入 \(\mathcal{U}\)，在保留排序的轨迹上统计。混合网络单调，所以在贪心联合动作仍属于 \(\mathcal{U}\) 的时间步上，保留排序与原贪心策略执行的是同一个动作。

## 结果

| | 保留排序 | 重排对应 |
|---|---:|---:|
| 平均回报 | 12.36 | 2.42 |
| 回报标准差 | 4.52 | 1.20 |
| 最低回报 | 8.04 | 1.36 |
| 最高回报 | 20.00 | 5.06 |
| 胜率 | 2/8 | 0/8 |
| 时间步数 | 215 | 182 |
| 候选集为空的比例 | 0 | 0 |
| 候选集大小的中位数 | 33 | 13 |

八个回合的回报如下。保留排序为 8.98、11.28、8.04、9.17、11.06、20.00、10.38、20.00。重排对应为 1.81、2.26、1.81、1.81、1.58、3.66、5.06、1.36。两组回报的取值范围不相交。标准差是这 8 个回合回报的标准差。

保留排序的 215 个时间步中，贪心联合动作有 82.3% 属于 \(\mathcal{U}\)，这些时间步上保留排序选出的动作与贪心动作一致。其余 17.7% 的时间步上，贪心联合动作没有在离线数据中出现；保留排序不执行它，而在当前合法的已出现联合动作中取 \(Q_{\mathrm{tot}}\) 最大者。

两条轨迹上候选集大小不同，是因为执行的动作不同，随后访问到的状态不同。重排对应的候选集中位数为 13，不是单元素集合，回报下降不是因为没有动作可以比较。

## 结论

这个离线检查点里被贪心策略使用的，是离线数据中出现过的联合动作之间的排序。同样一组 \(Q_{\mathrm{tot}}\) 数值，只打乱与这些联合动作的对应关系，平均回报就从 12.36 降到 2.42。贪心联合动作在 82.3% 的时间步上落在支持集内，并且此时与保留排序的选择相同，说明策略读取的排序定义在这些出现过的联合动作上，而不是定义在这组数值本身上。
