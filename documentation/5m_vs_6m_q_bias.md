# 5m_vs_6m：胜率看不出，偏差能看出

离线结束时胜率只有 0.22，但 Q 已经偏高：bias \(+2.51\)，归一化偏差 \(0.62\)，\(\tau\) 只有 0.69。在线一开始两边胜率都是 0.06（32 局的波动），bias 已经是 \(+3.2\)，约 77% 的步上 Q 高于真实回报。

| 环境步 | 无 OVM 回报 | 有 OVM 回报 | 无 OVM \(\tau\) | 有 OVM \(\tau\) | 无 OVM bias | 有 OVM bias |
|---|---|---|---|---|---|---|
| 0 | 10.2 | 10.2 | 0.73 | 0.73 | \(+3.2\) | \(+3.2\) |
| 1 万 | 1.3 | 7.9 | \(-0.64\) | 0.76 | \(-17.4\) | \(+7.3\) |
| 3 万 | 6.7 | 5.5 | 0.40 | 0.67 | \(-1.1\) | \(+9.8\) |

3 万步时两边胜率都是 0。没有 OVM 时 Q 先崩到 \(-17\)，排序反掉。有 OVM 时 Q 没有崩，而是继续抬高：bias \(+9.8\)，归一化偏差 \(4.6\)，99.5% 的步都是高估。沿轨迹的 \(\tau\) 仍有 0.67，因为 Q 和回报可以一起变、只是刻度差了几倍，所以 \(\tau\) 看不出这个高估。冻结离线 Q 在新轨迹上的 \(\tau\) 掉到 0.11，在线 Q 比它高大约 12。

这张图才是「胜率之外才看得出来」：40k 步里胜率没有把 OVM 判成更好，`q_bias` 和 `q_overestimate_rate` 显示 OVM 把离线阶段已有的高估又放大了。
