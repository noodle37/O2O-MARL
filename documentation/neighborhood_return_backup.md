# 邻域回报自举

在线更新仍然从离线 QMIX 检查点出发。冻结网络只负责指出离线贪心联合动作。团队价值的数值只向在线回报回归。自举不再使用各自最大动作的乘积，而是当前状态下、离线支持集里、离这个决策不远的那些联合动作。

符号如下。智能体个数为 \(n\)。离线数据里出现过的联合动作集合为 \(\mathcal S_{\mathrm{off}}\)。冻结网络给出的贪心联合动作为 \(u_{\bar{}}\)，在线网络的贪心为 \(u_{\mathrm{live}}\)，这一步实际执行的联合动作为 \(a\)。目标网络记为 \(Q^{-}\)。折扣为 \(\gamma\)，\(\lambda\)-回报的参数为 \(\lambda\)。

## 1. 载入并冻结提议

将离线 QMIX 载入在线网络和目标网络。再复制一份并停止其梯度。这份冻结网络之后只计算

\[
u_{\bar{}}(s)=\arg\max_{u} \bar Q(s,u),
\]

其中最大值按各智能体合法动作上的个体最大动作取得。\(\bar Q\) 的数值不进入时序差分目标，也不提供符号。

## 2. 当前状态上的邻域

对轨迹中的每个状态，三个锚是 \(u_{\bar{}}\)、\(u_{\mathrm{live}}\) 和 \(a\)。邻域 \(\mathcal N(s)\) 由这三条锚，以及 \(\mathcal S_{\mathrm{off}}\) 中与任一锚的汉明距离不超过 2、且各自动作都合法的联合动作组成。超过 \(K\) 个时保留距离更近的。默认 \(K=8\)。

\(\mathcal N(s)\) 的大小不随 \(|\mathcal A|^{n}\) 增长。一个不在 \(\mathcal S_{\mathrm{off}}\) 里的联合动作不能进入自举。

## 3. 用当前价值给邻域加权

自举值取目标网络在 \(\mathcal N(s')\) 上的加权平均。权重由这些联合动作自己的目标价值决定：

\[
\tau=\mathrm{Std}\{Q^{-}(s',u):u\in\mathcal N(s')\},
\]

\[
p(u\mid s')=\frac{\exp(Q^{-}(s',u)/\tau)}{\sum_{v\in\mathcal N(s')}\exp(Q^{-}(s',v)/\tau)}.
\]

标准差在这一批的全部有效候选上计算。它为 0 时令 \(\tau=1\)，权重退化为均匀。一步自举为

\[
\tilde Q(s')=\sum_{u\in\mathcal N(s')}p(u\mid s')\,Q^{-}(s',u).
\]

某个状态的邻域为空时，这一步退回目标网络的分解贪心，避免用 0 做自举。载入检查点时 \(Q^{-}\) 仍是离线价值，所以 \(p(u\mid s')\) 集中在 \(u_{\bar{}}\) 附近。回报改写 \(Q\) 之后，权重跟着改写后的价值移动。

## 4. \(\lambda\)-回报

环境奖励为 \(r_t\)，终止标志为 \(d_t\)。沿轨迹反向计算

\[
G_t=r_t+\gamma(1-d_t)\big[(1-\lambda)\tilde Q(s_{t+1})+\lambda G_{t+1}\big].
\]

在线网络对实际执行的联合动作给出 \(Q(s_t,a_t)\)。时序差分项与原训练相同，带系数 \(\tfrac12\)：

\[
\mathcal L_{\mathrm{TD}}=\frac12\big(Q(s_t,a_t)-G_t\big)^2.
\]

动作选择仍是在线网络的贪心，不读取冻结网络。

## 5. 离线贪心的单侧下界

\(G_t\) 还低于目标网络对 \(u_{\bar{}}\) 的价值时，这次更新不能把在线网络里这个联合动作的价值带到目标价值以下。已经不低于时，这一项没有梯度：

\[
\mathcal L_{\mathrm{floor}}=\mathrm{relu}\big(Q^{-}(s_t,u_{\bar{}})-Q(s_t,u_{\bar{}})\big)\,[G_t<Q^{-}(s_t,u_{\bar{}})].
\]

总损失为

\[
\mathcal L=\mathcal L_{\mathrm{TD}}+\mathcal L_{\mathrm{floor}}.
\]

\(G_t\ge Q^{-}(s_t,u_{\bar{}})\) 时只剩下时序差分，新的配合通过 \(G_t\) 写入。下界用的是目标网络里 \(u_{\bar{}}\) 的当前价值，不是 \(\bar Q\) 的幅度。目标网络按原间隔从在线网络复制，冻结网络不参与复制。

## 相对原来序数项的位置

原来的附加项要求在线价值差保持冻结价值的符号。现在没有符号，也没有第二套价值网络。冻结网络留下的是 \(u_{\bar{}}\) 这个联合动作：它占据邻域中的一个位置，并在回报还低于它的当前价值时挡住共享参数把它拉低。
