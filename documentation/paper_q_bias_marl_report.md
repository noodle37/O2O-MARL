# O2O MARL 中的 Q 值偏差与排序测量报告

> 协议来源：Yinmin Zhang et al., *A Perspective of Q-value Estimation on
> Offline-to-Online Reinforcement Learning*, arXiv:2312.07685v1。
> 本报告只复刻其**测量协议**，不迁移 SO2 算法。
>
> 数据截止：2026-10-20 23:16 CST。5m_vs_6m 两臂已跑到约 61k/300k；2halfcheetah
> 两臂已完成离线检查点与在线 t=0 评估，3M 在线运行仍在进行。最终检查点探针和
> 300k/3M 末尾读数将在训练结束后补入；结论性数值均标注了对应的 t_env。

## 摘要

1. **O2O MARL 确实出现大幅 Q 偏差，且方向会在在线阶段翻转。** 5m_vs_6m 关闭 OVM
   时，Q 从离线检查点的轻度高估（t=0：bias +1.54，高估率 68.5%）在 10k 步内翻转为
   严重低估：t=10,217 时 bias = **−32.64**、中位数 −35.15、低估率 **100%**、
   `(Q−G)/max(|G|,1)` = −24.55；到 61k 才回到 bias ≈ −1。
2. **O2O MARL 确实出现 Q 排序失效，但在 5m 上是暂态的。** 同一无 OVM 臂的滑窗
   Kendall τ（W=10）从 t=0 的 **0.407** 降到 t=30,520 的 **−0.712**（负窗口比例
   **100%**），整回合 τ 最低 **−0.769**；45.9k 后恢复为正，61.3k 时 τ10 = 0.565。
   连续负 τ10 的评估段为 20.4k–40.8k。
3. **OVM 开关给出了干净的对照：OVM 阻止排序崩塌，但没有消除偏差，而是把低估换成
   持续高估。** 5m OVM 臂从未出现负 τ10（最小即 t=0 的 0.407），61.3k 时 τ_full =
   0.858、τ10 = 0.758、负窗口 1.8%；但 bias 持续为 **+1.5 至 +5.5**，高估率
   67%–99.5%，61.3k 仍为 +4.58。固定种子探针在 25k/50k 上复现了同样的对照。
4. **2halfcheetah 是“弱离线策略 + 已失准离线 Q”的压力测试。** 离线检查点的固定
   种子读数为：return −416.9、Q 71.6、G −39.2、bias **+110.7**、高估率 **99.7%**、
   τ_full 0.047、τ10 0.028、负窗口 38.3%；在线 t=0（32 回合）为 bias +125.7、
   高估率 99.98%、τ_full −0.037、τ10 0.024。该 Q 值几乎不携带排序信息，且严重
   高估。3M 在线运行用于观察 TD 能否把这种病态 Q 拉回，结果待补。

## 二、指标定义

对当前贪心策略（ε=0）的一条完整回合轨迹：

- `Q_est(t) = Q_tot(s_t, u_t)`：QMIX mixer 对实际执行的联合动作给出的值；
- `Q_true(t) = G_t = Σ_{k≥0} γ^k r_{t+k}`：沿该轨迹从 t 起的折扣回报，γ=0.99，
  回合终止即停止累加；
- 团队奖励取各智能体奖励均值，与训练一致。

**偏差指标**

1. 原始偏差 `bias = Q − G` 的均值与中位数；
2. 符号稳定归一化 `(Q − G) / max(|G|, 1)`（主归一化口径）；
3. 论文逐字归一化 `(Q − G) / G`（仅作对照；2halfcheetah 的 G<0 时会翻转符号）；
4. 高估率 `P(Q>G)`、低估率 `P(Q<G)`；
5. 以回合为独立样本的聚类标准误，避免把回合内相关的时间步当作独立样本。

**排序指标**

1. 整回合 Kendall τ：一条回合内全部 `(Q_t, G_t)` 的 τ，再对回合取平均；
2. 论文滑窗 τ（主指标）：窗口 W=10 个连续决策、步长 1，窗口内计算 τ，回合内平均后
   跨回合平均；W=5/20 作敏感性；
3. 负窗口比例 `P(τ_window < 0)`；
4. 窗口 τ 的回合聚类标准误。

判定“存在偏差”的口径：高估/低估率显著偏离 50%，且原始偏差与归一化偏差的回合聚类
标准误不跨 0；同时报告 Q、G 的均值与仿射拟合 `G ≈ aQ+b`，以区分幅度偏差与排序偏差。

## 四、2halfcheetah：压力测试

离线检查点本身已经严重失真：数据集行为策略的回合回报为 +6924±1271，而该检查点的
评估回报为 −450.8；离线训练日志中 Q 均值从 0.4 升到 239，真实回报始终在 −50 附近，
偏差从 +54 升到 +287，高估率 99%–100%，整回合 τ 在 −0.20 至 0.21 之间。因此这里
不是“从强离线策略出发”的干净 O2O 证据，而是“弱策略 + 已失准 Q”的压力测试。

**固定种子探针（t=0，8 回合）**：return −416.93，Q 71.59，G −39.15，bias **+110.73**，
中位数 +98.79，SE 10.00，高估率 **99.7%**，低估率 0.3%，`norm_abs` 4.00，τ_full 0.047，
τ10 0.028（SE 0.066），负窗口 38.3%，τ5 0.040，τ20 0.019，仿射斜率 0.061。

**在线 t=0（32 回合）**：return −490.65，Q 79.70，G −46.03，bias **+125.73**，
中位数 +111.71，SE 5.94，高估率 **99.975%**，低估率 0.025%，`norm_abs` 3.92，
τ_full −0.037，τ10 0.024（SE 0.029），负窗口 42.7%。

**在线 t=100k（32 回合，仍未发生梯度更新）**：return −454.8，Q 74.7，G −43.2，
bias +117.9，中位数 +102.3，τ_full 0.039，τ10 0.010，负窗口 45%。两臂在该点
逐位相同——replay buffer 要到 128k 步才填满，此前 OVM 不可能影响参数；t=0 与
t=100k 的差别只来自评估环境种子的推进，不能解读为学习效果。

两套读数的绝对值不同（种子/回合数不同），但结论一致：Q 严重高估，且几乎不携带排序
信息（τ≈0，负窗口约四成）。关闭/开启 OVM 的两臂在 t=0 和 t=100k 完全相同，符合
“OVM 只在在线更新中起作用”的实现。

3M 在线运行（每 100k 评估、每 250k 保存）仍在进行。需要观察的问题：

1. 纯 TD 能否把 Q 从 +80 拉回，以及拉回过程中是否会像 5m 一样出现过冲/排序反转；
2. OVM 的离线锚定在 Q 已高估 +110 的情况下是否会让高估长期保持；
3. 在线策略回报能否从 −490 改善，以及偏差的改善是否先于排序的改善。

结果将在训练结束后以同一口径补入（在线轨迹 + 周期检查点探针）。

## 五、讨论

### 5.1 回答三个问题

**Q1：O2O MARL 是否存在 Q 估计偏差？** 存在。5m 无 OVM 臂出现 −32.6 的严重低估
（低估率 100%），OVM 臂出现 +1.5 至 +5.5 的持续高估（高估率最高 99.5%）。2hc 的
离线 Q 从起点即高估 +110 以上。偏差不是“有没有”的问题，而是方向和幅度会随在线阶段
变化。

**Q2：Q 排序是否不准，Kendall τ 是否下降？** 5m 无 OVM 臂的 τ10 从 0.407 降到
−0.712（负窗口 100%），整回合 τ 最低 −0.769；但这是暂态，45.9k 后恢复。OVM 臂
没有出现负 τ10。2hc 的 τ 从起点就接近 0，排序信息几乎不存在。因此“τ 下降”在 5m 上
是**早期在线阶段的暂态崩塌**，在 2hc 上是**离线 Q 本身失效**，两者机制不同。

**Q3：OVM 是否同时解决偏差与排序？** 没有。OVM 明确阻止了 5m 的排序崩塌，却把
偏差从负翻转成正，并长期保持高估。这与“值锚定保留排序、但不校正绝对水平”的解释
一致；若目标是同时消除偏差和排序误差，仅靠 OVM 不够（论文提出 SO2 正是为此）。

### 5.2 与纯在线对照的关系

仓库中已有一条 5m 纯在线对照（`checkpoints/pure_online_5m_vs_6m/online.jsonl`，
lr 3e-4、ε_start 0.2、无离线混合）。它在 10,036 步也出现 bias −21.20、τ_full −0.770，
到 111,953 步恢复到 τ 0.414。这说明早期 Q 崩塌并非 O2O 独有，而是该 MARL 设置在
早期在线学习中的一种不稳定现象；由于该对照的学习率、探索率和数据混合都与本实验
不同，不能直接与 OVM 开关做因果比较。可以确定的是：在**本实验控制住的 O2O 对照**中，
OVM 是防止排序崩塌的有效开关。

### 5.3 局限

1. 每个环境每个臂只有一个训练种子，结果是描述性量化，不做显著性推断；回合聚类
   标准误只刻画评估回合的抽样误差。
2. 在线评估 32 回合、固定种子探针 8 回合；5m 的胜率是二值结果，32 回合的胜率标准误
   约 0.09，因此胜率只作辅助。
3. 5m 回合仅约 27 步，W=10 的窗口覆盖约 37% 的回合，W=20 覆盖约 74%，与论文的
   长回合设定不同；本报告同时给出 W=5/10/20，崩塌点在三个窗口上均为负（除 25k
   的 W=5 为 −0.204），结论不依赖单一窗口。
4. 2hc 的离线检查点欠拟合且严重失准，只能作为压力测试；其 3M 在线结果在数据截止
   时尚未完成。
5. OVM 的 `lambda_memory` 在 300k 内保持 0.74–0.97（退火预算 7.68M 步），因此
   5m OVM 臂的高估可能部分来自“锚定尚未退火”；更长预算下的偏差走势需另行验证。
6. 在线日志中的 `train_ovm/*` 在无 OVM 臂是诊断重算，不是实际训练目标；实际损失
   已在代码中核对为纯 TD。
