# 5m_vs_6m 匹配协议 640 局终点评估报告

数据来源：`checkpoints/matched_protocol_20261020`，汇总表 `task8_matched_protocol_tables.md`，原始汇总 `logs/matched_protocol_summary.json`。

核心结论：在同一个离线 checkpoint、同一在线预算、同一评估协议下，UOT 联合排序与完整 OVMSE 达到相同水平（A−C = −0.9 个百分点）。两者相对干净 No-Ranking 基线的增益分别来自联合排序（+17.8 pp）和“OVM + 离线数据混合”的耦合（+18.8 pp）；单独打开 OVM 反而显著有害（−10.9 pp）。

## 1. 实验设置

五个臂共享以下条件：

- 离线 checkpoint：`checkpoints/ovmse_batch_20261014/5m_vs_6m_offline/ovmse_paper_seed1_best.pt`（t_env = 5,076,958）；
- 在线预算：3M 环境步，fresh run；seed = 1；
- 在线 TD、TD(λ)、target 更新、batch、优化器、buffer、ε 调度、评估间隔完全一致；
- 终点评估：final checkpoint，640 局，贪心策略，环境 seed 1，每 32 局一个 chunk（共 20 个 chunk）；Wilson 区间按 640 局计算。

| 臂 | 额外因子 | 说明 |
|---|---|---|
| A | ranking η = 0.1 | 固定联合排序，OVM 关，离线混合 0 |
| B | 无 | 干净 No-Ranking 基线（η = 0），OVM 关，混合 0 |
| C | OVM + 混合 0.1 | 完整 OVMSE 在线配方 |
| D | OVM | OVM 开，离线混合 0 |
| E | 混合 0.1 | OVM 关，离线混合 0.1 |

## 2. 终点结果

| 臂 | 条件 | 胜率 | 95% CI | 平均回报 |
|---|---|---:|---|---:|
| A | UOT ranking η=0.1 | **0.727** | [0.691, 0.760] | 17.30 |
| B | η=0（No-Ranking） | 0.548 | [0.510, 0.587] | 15.36 |
| C | OVM + mixing 0.1 | **0.736** | [0.700, 0.769] | 17.44 |
| D | OVM，无 mixing | 0.439 | [0.401, 0.478] | 14.50 |
| E | 无 OVM，mixing 0.1 | 0.542 | [0.503, 0.580] | 15.41 |

## 3. 什么是因子对比

“因子”（factor）是实验中由实验者主动开关的一个条件。本实验涉及三个因子：

- ranking：开（η = 0.1）或关（η = 0）；
- OVM：开或关；
- 离线数据混合：0 或 0.1。

单因素对照一次只改一个开关，只能回答“这个开关单独有没有用”。因子设计（factorial design）把所有开关组合成若干臂，一次实验同时估计每个开关的效果以及开关之间的相互作用。本报告中的 C、D、E、B 构成一个 2×2 因子设计：

| | 混合 = 0 | 混合 = 0.1 |
|---|---:|---:|
| OVM 关 | B：0.548 | E：0.542 |
| OVM 开 | D：0.439 | C：0.736 |

“因子对比”（factorial contrast）是从这些臂的结果中构造出的差值，用来分离某个效应：

- 主效应：例如 D−B 是“在混合为 0 时打开 OVM”的效果；
- 简单效应：例如 C−D 是“在 OVM 打开时加入混合”的效果；
- 交互效应：C−D−E+B = (C−D) − (E−B)，表示“混合在 OVM 打开时的效果”减去“混合在 OVM 关闭时的效果”。若为 0，两个因子可加；若明显不为 0，两者存在协同或拮抗。

差值区间使用配对 chunk bootstrap：五个臂在同一组 640 个评估情景上按 32 局切成 20 个 chunk，先在每个 chunk 内计算两臂差值，再对 20 个差值重采样 10,000 次，取 2.5%/97.5% 分位数。它回答的是“在这组固定评估情景下，两个 checkpoint 的差距是否稳定”，区间不跨 0 表示差距在评估抽样意义下可分辨。

## 4. 因子对比结果

| 对比 | Δ胜率 | 95% CI | Δ回报 |
|---|---:|---|---:|
| A−B（ranking 效应） | +0.178 | [0.127, 0.227] | +1.94 |
| C−B（OVMSE 总效应） | +0.188 | [0.125, 0.244] | +2.08 |
| D−B（单独 OVM） | −0.109 | [−0.158, −0.062] | −0.86 |
| E−B（单独 mixing） | −0.006 | [−0.053, 0.038] | +0.05 |
| A−C（UOT vs OVMSE） | −0.009 | [−0.058, 0.039] | −0.14 |
| C−D−E+B（OVM×mixing 交互） | +0.303 | [0.244, 0.361] | +2.89 |

逐行含义：

- **A−B = +0.178**：在 OVM 关闭、无离线混合时，加入固定联合排序使胜率提高 17.8 个百分点。这是第一个在干净 η=0 基线上测得的 ranking 效应。
- **C−B = +0.188**：完整 OVMSE 配方相对干净基线提高 18.8 个百分点，总增益与 UOT 排序几乎相同。
- **D−B = −0.109**：只打开 OVM、不加离线数据混合，胜率下降 10.9 个百分点。冻结离线 Q 作为 TD 目标的一部分，单独使用会损害在线学习。
- **E−B = −0.006**：只把离线数据混入 batch、不启用 OVM，胜率基本不变。离线数据本身不构成增益来源。
- **A−C = −0.009**：UOT 排序与完整 OVMSE 的终点差距不到 1 个百分点，区间跨 0。
- **C−D−E+B = +0.303**：强正交互。OVM 在无混合时效应为 −0.109，在有混合时效应为 +0.194；混合在无 OVM 时效应为 −0.006，在有 OVM 时效应为 +0.297。两个组件必须同时打开才产生增益。

## 5. 主要发现

1. **联合排序的收益有了干净对照。** B 是真正的 No-Ranking 基线（η = 0），A−B 的 17.8 pp 增益不能再由 support 过滤或旧的 `none` 臂解释。

2. **UOT 与 OVMSE 的差距在同协议下消失。** A 与 C 分别为 0.727 和 0.736，A−C = −0.009 [−0.058, 0.039]。历史上 0.617 对 0.667 的差距没有复现；该差距来自 checkpoint 来源和在线谱系差异，而不是 ranking 与 OVM 两种机制本身的优劣。

3. **OVMSE 的收益来自 OVM 与离线数据混合的耦合，而不是 OVM 单独起作用。** OVM 单独使用显著有害，混合单独使用无影响，二者联合产生 +18.8 pp。交互项 +30.3 pp 表明这是超加性的协同，而不是两个小增益的叠加。

4. **Q 偏差诊断与终点表现一致。** 在线 Q 相对折扣回报的平均偏差（正值为高估）：D 0.91、C 0.27、E 0.08、A 0.06、B 0.01。单独 OVM 的偏差最大、终点最差；加入离线混合后偏差回落，终点恢复。这与“冻结离线 Q 需要离线数据锚定”的解释一致。

## 6. 学习轨迹

periodic checkpoint 的 640 局评估（同一评估协议）：

| checkpoint | A | B | C | D | E |
|---|---:|---:|---:|---:|---:|
| 500k | 0.133 | 0.009 | 0.314 | 0.161 | 0.089 |
| 1.0M | 0.295 | 0.172 | 0.478 | 0.227 | 0.278 |
| 1.5M | 0.422 | 0.356 | 0.575 | 0.297 | 0.419 |
| 2.0M | 0.580 | 0.464 | 0.652 | 0.414 | 0.442 |
| 2.5M | 0.664 | 0.505 | 0.684 | 0.427 | 0.448 |
| 3.0M | 0.727 | 0.548 | 0.736 | 0.439 | 0.542 |

两种有效机制的时间形态不同：C 在早期明显领先（500k 时 0.314 对 A 的 0.133），A 在中后期持续追赶，到 3M 时两者收敛。B 与 E 全程接近，D 自 1M 起持续垫底。终点优势不是某个 checkpoint 的偶发峰值。

## 7. 结论

- 从同一离线起点出发，UOT 联合排序和完整 OVMSE 都能把 5m_vs_6m 的在线终点胜率从约 0.55 提升到约 0.73，二者没有可分辨的终点差距。
- OVMSE 的机制不是“OVM 本身更好”，而是“OVM 目标 + 离线数据混合”的互补组合；缺少离线混合时，OVM 是一个负向组件。
- ranking 的效应在干净 No-Ranking 对照下成立，且与 OVMSE 的总效应量级相当。
