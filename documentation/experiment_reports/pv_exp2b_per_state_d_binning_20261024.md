# 逐状态 D 分箱（P0-a，验证二缺失的一环）

## 摘要

本实验补的是《问题验证方案（基于已有数据）》第 2.4 节、也是第 4 节优先级 P0-a 的那一步：把 PV 实验一臂 C 与臂 B 的训练探针按同伴偏离度 $D(s)$ 分箱，做固定效应后的逐状态比较。它是纯后处理，不训练新模型，按用户要求用 `CUDA_VISIBLE_DEVICES=0` 和 `nohup` 启动（实际不占 GPU 计算）。

主结果：**两臂都没有通过预先写定的 R1**。在 $\lambda$ 已到下限的区段内，扣除同一探针点的平均误差后，高偏离（$>q_{95}$）与低偏离（$\le q_{50}$）的离线价值误差差为：

- 臂 C：**−0.189**，95% 聚类 bootstrap 区间 $[-0.318,-0.059]$，四箱不单调；
- 臂 B：**+0.013**，区间 $[-0.108,0.128]$（跨 0），四箱不单调。

臂 C 的差为负且区间不含 0，方向与“偏离越大、离线价值越不可靠”相反；臂 B 的绝对误差差跨 0，相对误差指标在下限区段为 $+0.124$ $[0.017,0.231]$，全程口径的绝对误差差为 $+0.131$ $[0.006,0.257]$。前者是第二指标，后者不属于 R1 规定的下限区段，二者都不能改变“R1 不成立”的判定。按第 2.5 节的规则，**形式判定为分支 C**：D 分箱不支持假设。同时，R4 在全程标准化回归中显示时间系数大于 D 箱系数（两臂都是），因此“按时间衰减在该任务上未被否定”这一反面结果（分支 D）也成立。正文不能选用第 6.3 节的版本 A 或 B；版本 C 最接近，但其中“有效性随状态变化”一句需要谨慎改写（见第七节）。

本报告同时记录一个对第 2.3 节预分析的重要修正：臂 B 在探针点层面的 $\rho(D,\text{误差})=0.501$ 在固定效应后消失，说明该相关主要来自探针点之间的差异，而不是同一时刻内的状态差异。

## 一、实验目的与在方案中的位置

《问题验证方案》的验证二要检验：离线知识是否有效，取决于当前状态下同伴行为是否仍在离线数据之内，而不是训练时间。方案预设的判据是：

1. R1：在 $\lambda$ 下限区段内，固定效应后高偏离箱的误差显著高于低偏离箱，且四箱单调（允许一处持平）；
2. R2：探针点内打乱 $D$ 后该差异消失；
3. R3：在新颖度三档内分别重复 R1，至少两档同向显著；
4. R4：全程回归控制 D 箱后，D 箱系数绝对值大于 $\log t$ 系数；
5. R5：q90/q99 阈值、臂 B 重复、相对误差指标下方向不变。

第 2.3 节的探针标量预分析只到“约 80 个探针点的聚合相关”这一层，无法区分状态差异与时间差异，也无法区分 D 与新颖度。本实验补的正是逐状态、带固定效应和聚类区间的那一层。

## 二、数据与口径

| 项目 | 内容 |
|---|---|
| 输入探针 | `checkpoints/pv_exp1/5m_vs_6m/C_seed1/probe.jsonl`、`checkpoints/pv_exp1/5m_vs_6m/B_seed1/probe.jsonl` |
| 行为模型阈值 | `checkpoints/pv_behaviour/5m_vs_6m/thresholds.json` |
| 分位阈值 | $q_{50}=6.7948\times10^{-6}$，$q_{90}=6.1272\times10^{-3}$，$q_{95}=1.3883\times10^{-2}$，$q_{99}=6.4423\times10^{-2}$ |
| 探针粒度 | 每约 1 万环境步一个探针点，覆盖 PV 实验一的约 0–1M 步；每点取最近 8 或 20 局，逐状态记录；臂 C 共 99 点、48,719 个有效状态；臂 B 共 100 点、50,523 个有效状态 |
| $\lambda$ 下限区段 | `lambda_memory <= 0.1 + 1e-9`，约 200k–1M 步；臂 C 79 点、39,353 状态；臂 B 80 点、41,119 状态 |
| 误差指标 1 | `abs_off_err` $=|Q^{\mathrm{off}}_{tot}-G|$（探针已有字段） |
| 误差指标 2 | 相对误差 `abs_off_err - abs_td_err` $=|Q^{\mathrm{off}}-G|-|TD-G|$，两者共用同一个 $G$ |
| 固定效应 | 每个探针点内先减去该点误差均值，再按 $D$ 分箱；D 效应因此只来自同一时刻的状态间差异 |
| 区间 | 按探针点聚类、2,000 次 bootstrap 的 2.5%/97.5% 分位；负对照打乱 200 次 |
| 不可分析臂 | 臂 A、臂 D 没有 `probe.jsonl`（目录中只有 online/pref/cov 文件），无法做本分析 |

**探针点聚类口径的边界。** 探针文件没有 episode 编号，同一探针点内的 8–20 局共享策略与时间，状态之间也不独立。按探针点聚类比按 episode 聚类更粗，区间仍可能偏乐观；本报告只把它当作描述性不确定性，不据此宣称强显著性。

**D 分布的极端偏斜。** 在线状态中约 52% 落在 $>q_{99}$ 箱，而 $q_{50}$ 只有 $6.8\times10^{-6}$。因此四箱实际上近似“近离线 / 轻微偏离 / 中等偏离 / 大幅偏离”，最上箱内部仍很宽，四箱对比无法分辨“刚刚越界”和“远离覆盖”的差别。这是分箱结果必须带上的结构限制。

## 四、结果

### 4.1 臂 C（主分析，只开 OVM，`mixing_ratio=0.0`）

$\lambda$ 下限区段（79 点、39,353 状态）：

| D 分箱 | 状态占比 | 固定效应误差 [95% CI] | 相对误差 | 触发率 | P(更接近 G \| 触发) | 打乱 D 后误差 | 状态数 |
|---|---:|---|---:|---:|---:|---:|---:|
| $\le q_{50}$ | 0.300 | +0.112 [+0.025, +0.196] | +0.161 | 0.796 | 0.057 | −0.001 | 11,825 |
| $q_{50}$–$q_{95}$ | 0.149 | +0.060 [−0.060, +0.183] | +0.233 | 0.742 | 0.057 | +0.009 | 5,879 |
| $q_{95}$–$q_{99}$ | 0.031 | −0.479 [−0.651, −0.293] | −0.253 | 0.702 | 0.059 | −0.004 | 1,231 |
| $>q_{99}$ | 0.519 | −0.053 [−0.107, +0.001] | −0.145 | 0.429 | 0.057 | −0.002 | 20,418 |

- 高偏离（$>q_{95}$，即上两箱合并）减低偏离（$\le q_{50}$）：**−0.189** $[-0.318,-0.059]$；四箱不单调。
- 相对误差同向：**−0.312** $[-0.408,-0.216]$。
- 阈值敏感性：q90 为 −0.209，q99 为 −0.164，方向不变。
- 打乱 D 的零分布：均值 −0.001，区间 $[-0.094,+0.107]$，覆盖 0；观测值落在零分布之外，说明负向差异不是分箱或抽样造成的假象。
- 全程口径（99 点、48,719 状态）：−0.011 $[-0.161,+0.146]$，方向消失。

**读法。** 在同一探针点内，高偏离状态的离线价值误差并没有更大：低偏离箱高于该点平均（+0.112），而 $q_{95}$–$q_{99}$ 箱明显低于平均（−0.479），最上箱接近 0（−0.053）。因此这不是“高偏离误差更大”的弱版本，而是方向相反；且四箱不单调，不能用一个“偏离越大越失效”的斜率概括。

每点内部把新颖度切三档，在每档内重做高偏离减低偏离的固定效应差（$\lambda$ 下限区段）：

| 新颖度档 | 臂 C | 臂 B |

- 两臂在“中/高新颖度”档内都为正，在“低新颖度”档内为负，且高/低偏离的样本量在三档内极不平衡（低档几乎没有高偏离状态，高档几乎没有低偏离状态）。这不是“D 的效应在控制新颖度后仍然稳定”，而是**符号随新颖度档变化**。因此 R3 的机械判定虽然为真（两档同向显著），但不能当作可分性的证据；R1 已经失败，R3 不改变分支。
- 低新颖度档的负差也提示：固定效应后的负相关主要发生在接近离线覆盖的状态内部，而不是“远离覆盖”的状态。

| 指标 | 臂 C | 臂 B |

## 五、解读

1. **预先写定的假设没有得到支持。** 在两臂的 $\lambda$ 下限区段，固定效应后的高偏离箱都没有显著高于低偏离箱。臂 C 甚至是显著更低（−0.189），臂 B 跨 0。四箱都不单调。按第 2.5 节，形式分支是 C。
2. **臂 C 的负号不是分箱假象。** 打乱 D 的零分布覆盖 0，而观测值在零分布之外；相对误差指标也给出同向的 −0.312。这说明在同一探针点内，高偏离状态的离线价值误差确实没有更大，甚至更小。一个可能的状态级解释是：高偏离状态多出现在战斗后期，$G$ 的量级与离线 Q 的偏差结构都不同于低偏离状态；本实验没有进一步分解这一点。
3. **第 2.3 节臂 B 的点层面相关不能升级为状态级证据。** 2.3 节给出 $\rho(D,\text{误差})=0.501$（点层面），但固定效应后该相关消失（+0.013，跨 0）。点层面的相关主要来自探针点之间的差异（策略随时推进、D 的分布在变），而不是同一时刻内高偏离状态更差。这是本次补跑最重要的方法学结论。
4. **R4 给出一个独立的负面结论。** 在全程标准化回归中，时间系数大于 D 箱系数；这与“按时间衰减在该任务上已经够用”一致。由于 R1 已失败，正式分支仍记为 C，但正文可以同时写入 R4 的结果（分支 D 的内容），把结论写成“D 不是合适的状态级判据，时间衰减在此任务上未被否定”，而不是反过来宣称时间调度一定错配。
5. **R3 的符号翻转说明 D 与新颖度无法分开。** 这与第 2.3 节 $\rho(D,\text{新颖度})=0.80$–$0.87$ 的共线性一致。即使不考虑 R1，也不能用这份数据声明“控制新颖度后 D 仍有效”。
6. **触发率随 D 下降。** 两臂都从低偏离箱的约 0.72–0.80 降到最高箱的约 0.37–0.43，说明 max 门本身对高偏离状态有一定规避作用。这与第 2.3 节第 3 点一致，也解释了为什么“失效仍保留”没有更高。

## 六、对写作的影响

按第 2.5 节和第 6.3 节：

- **不要使用版本 A（分支 A）或版本 B（分支 B）。** R1 不成立，版本 A/B 的前提都不满足。
- **使用版本 C**，但需要改两处措辞：

## 七、局限

1. **单训练种子。** 臂 C、臂 B 各只有一个种子；区间只反映探针点抽样与状态抽样，不包含训练随机性。
2. **臂 B 不是臂 C 的第二种子的重复**，而是不同配置（持续保守、混合 0.1）的对照。两臂一致失败只能说明“在这两个配置下都没有看到正效应”，不能当作独立复现。
3. **臂 C 的探针对应的是“只开 OVM、`mixing_ratio=0.0`”的 D 型配置**，不是完整 OVMSE（C 型）。第 1.5 节第 2 条的边界仍然存在；若要对应完整配方，需要 P3 的重跑。
4. **臂 A、D 没有 `probe.jsonl`**，无法做同样的逐状态分析；本报告只覆盖 B、C。
5. **D 的极端偏斜与最上箱过宽**（52% 状态 $>q_{99}$），四箱对比对“刚越界”和“远离覆盖”不敏感；如果要 salvage D 假设，应考虑连续 D 的样条/分位更细的分箱，或按局面阶段分层，而不是当前四箱。
6. **$G$ 是行为策略的实际折扣回报**，对离线价值天然不利；“更接近 G”的比例只能作箱间相对比较，不能当作绝对有效性。探针点聚类也可能低估区间宽度（点内状态相关）。
7. **固定效应只控制探针点，不控制 episode 或局面阶段。** 高偏离状态在点内可能集中在战斗后期；新颖度分层只能部分缓解，不能完全排除阶段混杂。
