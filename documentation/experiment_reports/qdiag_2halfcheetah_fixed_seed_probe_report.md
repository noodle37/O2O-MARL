# 2halfcheetah O2O Q 诊断：固定种子探针扫描报告

> 数据来源：`checkpoints/qdiag_20261020/probes/2halfcheetah_{off,on}_t*.json`（固定种子探针，
> `scripts/measure_paper_q.py --seed 12345 --episodes 8`）、
> `checkpoints/qdiag_20261020/2halfcheetah_{off,on}/online.jsonl`（在线 32 回合评估）。
> 探针扫描执行于 2026-10-21 15:19–15:26 CST。
>
> 本报告填补 `documentation/paper_q_bias_marl_report.md` 中 2halfcheetah 一节
> "3M 在线运行用于观察 TD 能否把这种病态 Q 拉回，结果待补" 的占位。
> 实验设计见 `documentation/paper_q_bias_marl_experiment_design.md`。

## 摘要

1. **两臂起点逐位一致，对照有效。** t=0 两臂全部指标完全相同（return −416.93、bias +110.73、
   τ_full 0.0465），验证了同一离线检查点与同一组评估种子。
2. **TD 没有把病态 Q 拉回，两臂都没有。** 关闭 OVM 时 bias 从 110.73 到 128.88 基本不动，
   τ_full 全程在 −0.11 ~ +0.04 区间徘徊，高估率恒为 100%。在线 TD 无法修复已失准的离线 Q。
3. **OVM 保住了排序、破坏了幅度。** 开启 OVM 时 bias 单调恶化 110.73 → 431.43（约 3.9 倍），
   return 从 −416.93 掉到 −1137.04；但 τ_full 在 t=750k/1M 明显高于对照臂
   （0.1825 vs −0.0832、0.1169 vs 0.0413）。
4. **仿射拟合给出了机制层面的区分。** t=1M 时对照臂 `G ≈ 0.018·Q − 39.78`（Q 几乎不携带 G 的信息），
   OVM 臂 `G ≈ 0.694·Q − 331.07`（Q 能跟上 G 的方差）。排序保留与幅度破坏同时成立。
5. **结论对评估协议不敏感。** 固定种子探针与在线 32 回合 jsonl 在 bias 分离量上一致
   （对照臂 ~130–140，OVM 臂 ~400–430），高估率均为 100%。
6. **本组的 bias 测量与既有 OVM 偏差测量冗余，故在 t≈1.2M/3M（40%）处终止。** 详见第七节。

## 二、固定种子探针结果

Q 真值定义为沿当前贪心策略（ε=0）完整回合轨迹的折扣回报 `G_t = Σ γ^k r_{t+k}`，γ=0.99，
团队奖励取各智能体奖励均值。`bias = Q − G`。

## 五、仿射拟合：幅度偏差与排序偏差的分离

按实验设计第四节要求，对 `G ≈ a·Q + b` 做仿射拟合以区分两类偏差。斜率 a 反映 Q 能否跟上 G 的方差（排序），
截距与均值差反映整体偏移（幅度）。

| 臂 | t_env | 拟合 | a（排序） | Q 均值 | G 均值 |
|---|---|---|---|---|---|
| OFF | 0 | G ≈ 0.061·Q − 43.49 | 0.061 | 71.59 | −39.15 |
| OFF | 1,000,000 | G ≈ **0.018**·Q − 39.78 | 0.018 | 90.77 | −38.11 |
| ON | 0 | G ≈ 0.061·Q − 43.49 | 0.061 | 71.59 | −39.15 |
| ON | 1,000,000 | G ≈ **0.694**·Q − 331.07 | 0.694 | 327.79 | −103.64 |

t=1M 时对照臂斜率降到 0.018——Q 的波动几乎不预测 G 的波动，排序信息基本丢失；
OVM 臂斜率为 0.694，Q 能跟上 G 的大部分方差，排序被保留。
但 OVM 臂 Q 均值 327.79 对 G 均值 −103.64，幅度偏移 +431。**两类偏差在同一臂上反向分离**，
这是"OVM 保住排序、破坏幅度"最直接的量化证据。

## 六、与在线 jsonl 的交叉验证

在线评估为 32 回合，但环境重置种子未逐回合固定，2halfcheetah 回合间初始状态方差大，
因此在线 jsonl 按设计仅作连续监控，跨时间可比读数以固定种子探针为准。两者对照如下：

| 臂 | 协议 | 末次 t_env | bias | 后半段 bias | 后半段 return | 高估率 |
|---|---|---|---|---|---|---|
| OFF | 固定种子探针 | 1,000,000 | 128.88 | — | — | 100% |
| OFF | 在线 32 回合 | 1,200,000 | 138.30 | 139.8 ± 6.9 | −464.4 ± 26.1 | 100% |
| ON | 固定种子探针 | 1,000,000 | 431.43 | — | — | 100% |
| ON | 在线 32 回合 | 1,200,000 | 407.58 | 408.8 ± 23.3 | −997.9 ± 268.2 | 100% |

两种协议在 bias 的绝对量级与两臂分离上一致（对照臂 ~130–140，OVM 臂 ~400–430），
高估率均为 100%，说明**结论不依赖于评估协议**。

差异体现在方差上：在线 jsonl 的 τ_full 波动明显更大（OVM 臂在 −0.028 ~ +0.273 间摆动），
return 的后半段标准差达 268.2（对照臂仅 26.1）。这正是设计文档要求以固定种子探针作为
跨时间可比读数的原因——在线 jsonl 的噪声会掩盖 τ 的细微变化，但不改变 bias 的结论。

## 七、与既有 OVM 偏差测量的关系（提前终止的依据）

本组的 bias 测量与此前三次独立测量重复，故在 40% 处终止：

|---|---|---|---|---|---|

## 八、结论

1. **在线 TD 无法修复已失准的离线 Q。** 在 2halfcheetah 这一"弱离线策略 + 已失准离线 Q"的
   压力测试设定下，关闭 OVM 时 bias 全程停在 110–151、τ_full 在 ±0.11 内徘徊、高估率恒为 100%，
   1M 步内没有任何恢复迹象。这回答了 3M 预算真正要回答的问题。
2. **OVM 的作用是保留排序、牺牲幅度，而非降低偏差。** bias 从 110.73 恶化到 431.43（3.9 倍），
   return 从 −416.93 掉到 −1137.04；同时 τ_full 在 t=750k/1M 显著高于对照臂，
   仿射斜率 0.694 vs 0.018。两类偏差在同一臂上反向分离。
3. **该结论稳健**：对评估协议（固定种子探针 vs 在线 32 回合）、窗口宽度（W=5/10/20）均不敏感，
   且与此前 5m_vs_6m 与 3s5z 的两组独立测量定性一致。
4. **本组不构成 OVM 整体优劣的证据。** 5m 上 OVM 的 return 略优（10.5 vs 10.4），
   3s5z 上 OVM 后期更差（13.93 vs 15.57），方向不一致；2halfcheetah 作为压力测试更不能外推。

## 九、局限

1. **单训练种子**，按设计仅作描述性量化，不作显著性推断。回合聚类标准误只刻画评估回合的抽样误差。
2. **2halfcheetah 离线策略本身欠拟合**：离线检查点 `best_eval_return = −450.8`，
   而数据集行为策略回合回报为 `+6924 ± 1271`。两臂都从病态起点出发，
   "OVM 更差"是在两边都坏的设定下成立的，不可外推到强离线策略的 O2O 场景。
3. **在线评估环境种子未逐回合固定**，在线 jsonl 的 τ 与 return 波动大；本报告的跨时间结论
   以固定种子探针为准，但探针仅 8 回合，τ 的标准误仍有 0.03–0.13。
4. **只对比了 OVM 开/关两档**，未涉及 λ 衰减计划能否在保住前期好处的同时避免幅度破坏
   （该问题在 3s5z 报告中已提出，本组同样未回答）。
5. **训练在 40% 处终止**，1.2M–3M 区间的轨迹未知。虽然 1M 内的趋势已单调稳定，
   但不能排除后期出现反转（5m 上就出现过 return 从 1.18 爬到 11.86 的大幅后期变化）。
