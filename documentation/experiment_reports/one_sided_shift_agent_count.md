# 单智能体对协作结果的影响：跨队伍规模（3 / 5 / 8 个智能体）的对照

> 实验：`one_sided_shift`（单边策略变动实验），SMAC v1，三张不同友方规模的地图。
> 每条件 640 局，`eval_seed = noise_seed = 424242`，离线基线为各图的 OVMSE `ovmse_paper_seed1_best.pt`。
> 5m_vs_6m 部分见 [one_sided_shift_5m_vs_6m.md](one_sided_shift_5m_vs_6m.md)；本文补上 3m / 8m 两档并做跨图对齐。

---

## 0. TL;DR

**单智能体对协作结果的影响随队伍规模显著衰减。** 在 ε=0.1 的同等扰动强度下，只让一个智能体偏离（条件 C）造成的团队回报损失，从 3 人队的 **−2.18** 降到 5 人队的 **−0.65**、8 人队的 **−0.60**；它占"全员偏离"总损伤的比例从 **0.438** 降到 **0.173**、**0.132**。

三张图上"队友偏离造成的损失"始终远大于"自身偏离造成的损失"（ε=0.1 时 `C − A` = +2.80 / +3.13 / +3.94），即团队退化主要来自队友而非自己。

**但这条跨图读数不能当作"智能体数量"的干净因果效应**——三张图的对称性、难度与基线胜率都不同（0.727 / 0.259 / 0.909），详见第 6 节。

## 1. 实验设计

### 1.1 四个条件

焦点智能体固定为 0（5m_vs_6m 另做了焦点旋转，见 4.3）：

| 记号 | 含义 | 偏离的智能体数 | 读出的量 |
|---|---|---|---|
| O | 全队离线贪心，不扰动 | 0 | 基线 |
| A | 全队偏离 | N | 全员偏离的总损伤 |
| B | **焦点固定离线贪心**，仅 N−1 个队友偏离 | N−1 | 队友合计的贡献 |
| C | **仅焦点偏离**，队友固定离线贪心 | 1 | **单个智能体的边际影响** |

核心对比是 **`C − O`**（单智能体影响）与 **`B − O`**（其余队友合计影响）。

### 1.2 扰动机制

每个未被豁免的智能体在每一步以概率 ε 取一个均匀随机的合法动作；随机数由 FNV-1a 哈希 `(noise_seed, episode, step, agent, stream)` 生成，因此 A/B/C 在同一步、同一智能体上的"是否扰动 / 抽到哪个动作"完全一致，只有可扰动集合不同。

### 1.3 统计口径

- 跨条件使用**非配对 bootstrap**（4000 次重采样，每次条件独立重采样 640 局）：SC2 在同一进程内原地 restart，只有第 0 局的初始状态在跨进程时严格相同，第 1 局起的初始状态依赖上一局轨迹；每局重开 SC2 进程约需 12 秒，640 局不可行。
- 胜率给 Wilson 95% CI。
- 同一条件内部的确定性由 `O` 与独立进程 `O_repeat` 的逐局回报完全一致验证（三张图均通过，`deterministic: true`）。

### 3.1 两条核心读数

1. **单智能体影响随 N 衰减**：|ΔC| = 2.18 → 0.65 → 0.60；占全员损伤的份额 0.438 → 0.173 → 0.132。在 8 人队里，一个人偏离只掉 0.60 分 / 0.069 胜率，而另外 7 人一起偏离掉 4.11 分 / 0.453 胜率——**个人错误在大队里几乎被吸收，团队损失几乎全部来自队友**。

2. **队友影响始终压倒自身影响**：`C − A` = +2.80（3m）/ +3.13（5m）/ +3.94（8m），即"只让自己偏离"比"全员一起偏离"好这么多。5m_vs_6m 上 5 个焦点位置全部同向（`B` 在 5/5 个焦点显著低于 `O`）。

两个归一化视角：

- **\|ΔC\|/\|ΔA\|**（单人份额）：三张图上**都随 ε 增大而上升**（小队上升更快）。直觉是——ε 小时大家只是偶尔走错步，团队靠冗余吸收；ε 大时单人错误本身就成了主导失效模式。

## 6. 结论与解释边界

### 6.1 结论

1. **单智能体对协作结果的影响随队伍规模显著衰减。** ε=0.1 时 |ΔC| = 2.18 / 0.65 / 0.60，单人份额 0.438 / 0.173 / 0.132；8m @ ε=0.05 甚至**统计上测不出**（CI 含 0）。
2. **人均破坏力也随规模下降**：`ΔB/(N−1)` = −1.85 / −0.81 / −0.59（ε=0.1）。
3. **团队退化主要来自队友而非自身**，三张图一致：`C − A` = +2.80 / +3.13 / +3.94。自身不犯错并不能阻止团队退化——只要队友策略发生偏离，即使焦点智能体 100% 执行离线贪心，回报、胜率和协同指标都显著下降。
4. **损伤的可加性有条件**：ε ≤ 0.2 时接近按人头线性；ε=0.3 时超线性（单人损伤达均摊值的 2.0~2.4 倍）。

### 6.2 边界与必须承认的混淆

- ⚠️ **跨图比较不是干净的"智能体数量"消融。** 三张图在**对称性**（3m/8m 对称 Marine vs Marine，5m_vs_6m 非对称）、**难度**与**基线胜率**（0.727 / 0.259 / 0.909）上都不同。"影响随 N 衰减"这个读数里混合了地图性质，**不能直接当作纯 N 的因果效应**。
- **基线胜率带来的天花板效应**：8m 队本来就有 91% 的局会赢，单人偏离的可损失空间被压得很小。按相对基线胜率折算，单人偏离造成的胜率损失为 3m **−23%**、5m **−19%**、8m **−7.6%**——衰减依然存在，但幅度远小于绝对值口径。
- **要做干净的 N 消融**，应使用 SMAC 同族的对称 Marine 图（`3m` / `8m` / `25m`，均已定义于 `smac_maps.py`）取点，避免对称性与胜率的共变；`25m` 目前尚未跑过。
- **跨条件非配对**：SC2 原地 restart 使初始状态在跨条件下不可逐局配对，故用非配对 bootstrap。640 局足以给出很窄的 CI，但初始地图序列在条件间并非逐局相同。
- **单图单种子**：三张图各一条离线基线（seed 1），没有种子层面的复制。
- **A/B/C 扰动的智能体数量不同**（N / N−1 / 1），三者的排序只能作描述性分解；干净的因果比较是 **`C − O`**（单智能体）与 **`B − O`**（队友合计）。
