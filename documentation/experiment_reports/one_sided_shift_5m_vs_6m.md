# 5m_vs_6m 单边策略变动实验：自身固定离线贪心，仅队友偏离

> 实验日期：2026-11-01。离线基线 `ovmse_paper_seed1_best.pt`，每个条件 640 局，`eval_seed=noise_seed=424242`。所有数据由 `scripts/run_one_sided_shift.py` 产生，由 `scripts/analyze_one_sided_shift.py` 聚合。

## 1. 摘要

- **主张成立**：焦点智能体自身始终执行离线贪心、完全不扰动，仅让 4 个队友以概率 ε 取随机合法动作，团队回报仍显著下降。ε=0.1 时 B 比全离线 O 低 **3.26**（−3.660, −2.830），胜率从 **25.9% 降到 5.8%**。
- **自身是否偏离不是主因**：B（仅队友偏离）与 A（全队偏离）几乎相同，ε=0.1 时 B−A 仅 **+0.53**（+0.23, +0.82）；C（仅自身偏离）只下降 **0.66**。
- **5 个焦点位置全部一致**：ε=0.1 时 B 的回报降幅为 −2.92 ～ −3.26，C 的降幅为 −0.66 ～ −1.35。
- **协同同步退化**：B 在 ε=0.3 时 focus-fire 从 0.864 降到 0.508，attack-share 从 0.667 降到 0.333，终局存活敌人从 1.33 增至 4.48；C 的对应值为 0.809 / 0.574 / 2.39。
- **自然替换复现同向结论**：把仅队友替换为 MU-APR 在线权重、自身保持离线，四个在线来源的 B 都低于 O（−0.89 ～ −4.44）。MU-APR seed1/2 的全在线队本来强于离线（14.24 / 14.76 > 12.44），混合队 B 仍跌到 10.42 / 11.54，出现明显的混合协同惩罚。
- **实现校验通过**：B 中焦点的扰动计数恒为 0，C 中非焦点恒为 0；实际扰动率与 ε 完全吻合；`O` 与独立进程重跑的 `O_repeat` 逐局回报完全一致。

## 3. 方法

- **扰动噪声**：每个未被豁免的智能体在每一步以概率 ε 取一个均匀随机的合法动作；随机数由 FNV-1a 哈希 `(noise_seed, episode, step, agent, stream)` 生成，因此 A/B/C 在同一步、同一智能体上的“是否扰动/抽到哪个动作”完全一致，只有可扰动集合不同。默认 `noise_seed=None` 时保留原顺序 RNG 行为，旧实验可原样复现。
- **逐局指标**：回报、胜负（`battle_won`）、长度、超时、attack-share、focus-fire 率、终局存活友军/敌军、离线 mixer 对实际执行联合动作的 `Q_tot`（仅诊断量）、以及每智能体的扰动 trials/events/changes。
- **统计**：胜率给 Wilson 95% CI；回报/胜率差给 **非配对 bootstrap 95% CI**（4000 次重采样，每次条件独立重采样 640 局）。
- **为什么是非配对**：SC2 在同一进程内原地 restart，只有第 0 局的初始状态在跨进程时严格相同；第 1 局起的初始状态依赖上一局轨迹。每局重开 SC2 进程约需 12 秒，640 局不可行。因此跨条件不能逐局配对；同一条件内部的确定性由 `O` 与独立进程 `O_repeat` 的逐局回报完全一致来验证。
- **解释边界**：A/B/C 分别扰动 5/4/1 个智能体，三者排序是描述性分解；核心因果比较是 **B vs O**（自身固定），不受扰动智能体数量混淆。`q_off_tot` 混合了不同策略来源，不是一致的团队价值，只作固定函数诊断量。

## 5. 结论与解释边界

1. **自身不犯错并不能阻止团队退化**：只要队友策略发生偏离，即使焦点智能体 100% 执行离线贪心，回报、胜率和协同指标都显著下降；ε=0.1 时胜率从 25.9% 降至 5.8%。
2. **自身偏离的边际贡献很小**：B−A 在 ε=0.1～0.3 仅 +0.53～+0.55；而 C 的降幅明显小于 B。团队损失主要来自队友偏离而非自身偏离。
3. **自然替换同样成立**：把队友换成在线微调权重、自身保持离线，三个 MU-APR 来源的 B 都低于 O，且低于对应的全在线队 A，形成混合协同惩罚；弱偏移来源 PV C_seed1 上 B≈A 且都低于 O，仅自身替换与 O 无显著差异。
4. **协同机制**：队友偏离首先破坏 focus-fire 与攻击参与率，随后表现为终局存活敌人增多、胜率下降；自身单独偏离对 focus-fire 的影响小得多。

**边界**：

- 跨条件使用非配对 bootstrap；虽然 640 局足以给出很窄的 CI，但初始地图序列在条件间并非逐局相同。
- A/B/C 扰动的智能体数量不同（5/4/1），A/B/C 的排序只能作描述性分解；主张的干净因果比较是 B vs O。
- Grid 2 的“下降”依赖在线权重的偏移方向：MU-APR seed1/2 单独看是更强的策略，但混合后仍产生协调损失；这支持“偏离/错配”而非“在线策略更差”的解释。
