# 5m_vs_6m ranking loss 分叉实验分析


## 一、实验目的与设计

**要回答的问题**：UOT 在 5m_vs_6m 上的在线微调，后期表现不及 OVMSE。一个候选原因是 ranking loss——约束在线策略保持离线教师动作排序的正则项——栓住了后期适应。本实验直接检验：训练中途把 ranking loss 撤除或衰减，能否改善后期表现。

**实验设计**：先用父 run 从离线 checkpoint 出发在线训练到 t_env=约 100 万步（逐 seed 分叉点 1,009,049、1,009,129、1,000,325），冻结完整的训练器快照；再从同一快照分出三条支线，除 ranking loss 权重外完全相同——continue 按原设置保留（权重 η 全程保持 0.1），off 在分叉点立即置零，decay 从分叉点起线性衰减到零。三条支线各继续训练约 199 万步，至 t_env≈2,998,811。

**评估方式**：分叉点 checkpoint 与三个终局 checkpoint 都在同一环境种子下评估 640 集（贪心策略，胜率附 Wilson 95% 置信区间），三个分支同 protocol，可直接配对比较。训练过程中另有定期评测，但每个评测点只跑 32 集，精度远低于终局评估（精度分析见第二节）。

## 四、与 OVMSE 在线运行的对比

作为参照，OVMSE 在同一地图、相同在线设置下，尾段胜率均值为 0.725（共 298 个评测点，与主指标同口径）。逐 seed 取三个分支的尾段胜率最高值：uot_fork_5m_vs_6m_seed1_formal 0.575（较 OVMSE 低 0.150）、uot_fork_5m_vs_6m_seed2_formal 0.731（较 OVMSE 高 0.006）、uot_fork_5m_vs_6m_seed3 0.681（较 OVMSE 低 0.044）；全部 9 个分支尾段的均值为 0.632，较 OVMSE 低 0.093。主指标的 95% 不确定范围约 ±0.075：说明与 OVMSE 的差距只在 uot_fork_5m_vs_6m_seed1_formal 上超出主指标的不确定范围，其余 seed 上分支尾段已与 OVMSE 同水平。


## 五、结论


**三个分支差异不明显（配对差 ≤ 0.05）。** 判定依据：决胜指标（640 集终局配对评估）。按事前约定的多种子判定规则（3 个 seed 方向一致且 640 局配对差均值 ≥ 0.10 记为明显更好；|均值| < 0.05 或方向不一致记为无差异；其余记为趋势不明）：640 集终局评估上 off 与 decay 相对 continue 的配对差均值为 0.052 与 0.024（方向不一致（2 正 / 1 负） / 方向不一致（1 正 / 2 负）），off 与 decay 之间 0.027。训练诊断与这一读法一致：continue 支线的 ranking loss 权重全程保持 0.1 不减（尾段其损失相对 TD loss 的贡献约 1.9%），off 从分叉点起、decay 逐步不再受其影响；终局评估捕捉的是整个分叉后窗口累积下来的差异。


**这一结论没有回答的问题**：第一，保留 ranking loss 与撤除/衰减在终局评估上无可测差异，“无差异”的原因——约束与在线证据不冲突，还是冲突被探索、回放、更新次数等因素抵消——本实验没有分离；第二，为什么 uot_fork_5m_vs_6m_seed1_formal 上三个分支都追不上 OVMSE（见第四节），说明差距还有 ranking loss 之外的原因，需要在探索策略、经验回放、更新次数、表示能力等方向上继续排查。


## 六、事前约定的结果解读框架

三种可能的结果对应三种解释：

- 撤除或衰减分支明显更好：说明持续的排序正则限制了后期适应，后续可以研究按在线证据逐步撤除约束；
- 继续保留分支最好：说明离线偏好仍然有益，后期表现不及 OVMSE 的原因在别处（如探索策略、经验回放、更新次数、表示能力）；
- 三个分支无差异：说明 ranking loss 不是造成差异的主因；注意即使撤除分支更好，也只说明撤除约束有益，不能说明教师模型的排序已经失效。


## 七、局限

- 3 个随机种子：分支间差异在全部 seed 上按同一协议测量，逐 seed 配对差见第 2.2 节；
- 两个指标精度差异大：结论以 640 集终局评估为准，主指标（每评测点 32 集）分辨不出 0.1 以下的差异；
- 640 集评估的 95% 半宽约 0.04，0.02 以下的分支间差异（如 off 对 decay）测不出；
- 本实验只检验了“撤除/衰减 ranking loss”这一个干预，没有分离造成终局差异的具体机制。
