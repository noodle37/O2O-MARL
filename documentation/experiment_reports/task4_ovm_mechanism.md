# OVM 价值约束机制诊断（任务四：直接验证 OVM 的价值约束机制）
> 本报告由 `scripts/analyze_ovm_diag.py` 自动生成；数据来源 `checkpoints/ovm_diag_20261017/<图>_<臂>/online.jsonl`。

## 一、实验目的与设计
**要回答的问题**：OVM 的价值约束机制是否真正起作用。这可以拆成两个层次：第一，它是否像设计那样，在训练过程中把回归目标持续抬高到普通 TD target 之上；第二，这一抬高是否通过推高在线 Q 值、改变动作之间的排序，最终造成学习表现的差异。本实验对第一个问题做直接测量，对第二个问题给出一组受控对照证据。
**实验设计**：在 2halfcheetah、2s3z、5m_vs_6m 三张图上各做一组对照，每组两条臂——`on` 臂启用 OVM（`transfer.mode=ovmse`），`off` 臂不启用（`transfer.mode=full_td`）。两条臂从同一个离线 checkpoint 出发，随机种子、探索率 ε 的衰减计划、训练批次构成、目标网络更新频率、诊断口径逐项相同（由 `scripts/make_ovm_diag_configs.py` 校验，除干预项与输出路径外零差异）。因此两条臂在表现上的任何差异，都只能归因于 OVM 这一个变量。
**测量方式**：机制指标在两个口径上测量。一是一批统一的固定样本（每张图从同一离线数据集用固定种子抽取 128 条完整 episode），保证跨臂、跨时间点同口径；二是训练过程中实际采样的批次，用来验证固定样本上的读数不是由数据分布特殊造成的。此外，`off` 臂也记录反事实的 OVM 目标（即假设启用会被抬高多少），作为对照。

## 六、结论

**结论一：OVM 确实在持续抬高训练目标，这一点由直接测量证实。**依据是第二节的激活率与上抬幅度两项指标：在三张图上，启用 OVM 的臂从第一个到最后一个评测点，两项指标始终大于 0；第四节进一步显示，训练实际采样批次上的读数与固定样本一致，因此这不是测量口径造成的假象。这项结论只依赖对训练目标的测量本身，不需要任何因果假设。抬高的实际效果还受当时生效的 λ 调制：5m_vs_6m 上 λ 已衰减到 0.100，固定样本上的原始上抬为 1.341，实际作用于目标的上抬只有 0.134。

**结论二：目标抬高是否导致性能差异，本实验不能下此结论。**如果“抬高目标 → 拉高在线 Q → Q 尺度膨胀、动作排序改变 → 表现变化”这条链成立，两条臂的诊断量应该在三张图上都按同一方向分离。实际只有 2halfcheetah 一张图符合（启用 OVM 后 Q 值尺度显著膨胀，回合回报明显更差），2s3z 与 5m_vs_6m 上两条臂表现接近。因此，本实验证明的是“OVM 抬高了训练目标”，不能证明“这一抬高造成了性能差异”。

**要把结论二推进为因果结论，还需要**：对比 λ 固定为 1 与 λ 衰减两档设置，分离“是否抬高目标”与“抬高幅度如何随时间变化”两个因素；把冻结的离线 Q 值替换为同期目标网络的 Q 值做消融，排除离线 Q 估计过时的影响；并补充多个随机种子的重复实验。

**局限**：每个设置只运行了一个随机种子；固定样本取自离线数据集，与在线交互产生的数据分布存在差异（已通过训练过程读数与训练结束时的经验池快照交叉验证）；诊断指标仅在训练评估点记录，并非每个环境步连续采集；2halfcheetah 为连续控制任务，不适用胜率指标。
