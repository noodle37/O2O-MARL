# 离线教师排序可靠性的时间演化（任务二，时间演化部分）

## 摘要

固定任务二测过的同一份冻结离线 teacher（`checkpoints/ovmse_paper_5m_vs_6m/ovmse_paper_seed1_best.pt`，只读 Q_tot），把「后续策略」从两个离线策略换成一串在线训练不同时刻的策略（在线初始化、标准 UOT 主线每 50 万步的中间检查点、任务三分叉快照、continue/off/decay 三个 3M 终点），在任务二相同的状态集与动作对上做分支回放，测量 teacher 排序与真实回报排序的一致率。**两个批次均已完成：Batch1（7 个后续策略，11,263 条记录）一致率 0.605–0.633（算法对 0.612–0.629），相对 teacher 的配对差全部在 ±0.03 以内且 95% CI 跨 0；Batch2（标准 UOT 主线 6 个中间检查点，10,008 条记录）一致率 0.622–0.669（算法对 0.622–0.681），相对 teacher 的配对差为 +0.008 → +0.063 的微弱上漂，全程没有下降。** 结论与任务二静态版 Q4（可靠性是 critic 自身的属性，不随后续策略改变）一致：**离线 teacher 的偏好相对于当前后续策略的可靠性不随在线训练变化**——时间轴从 3 个点加密到 13 个点后结论不变，且没有"后续策略变强后教师偏好过期"的迹象（若过期，一致率应随训练下降；实测主线臂相对 teacher 的差方向为正）。

**答：不随在线训练变化（两批合起来 13 个臂、t=0 到 300 万步的完整时间轴上依然如此）。** Batch1 的七个臂挤在 0.605–0.633 的窄带里，全部 CI 互相重叠；Batch2 的主线六点（算法对）为 0.622 / 0.637 / 0.668 / 0.662 / 0.652 / 0.681，CI 同样互相重叠且与 Batch1 各臂交叉。在线臂从 t=0 到 t≈3M（跨度 300 万步，覆盖 UOT 在线微调全程）算法对一致率 0.614→0.612–0.681：Batch1 内最大落差 0.015；主线六点相对 teacher（A）的配对差为 +0.008 → +0.063 的微弱上漂（第三节），方向是"更可靠"而非"过期"。配对检验同样支持这一读法：三个分支终点相对分叉快照的差为 +0.010 / −0.001 / −0.017，全部跨 0；主线相邻检查点之间的差（≤ ±0.028）也全部跨 0。CI 不跨 0 的只有 main1M5 / main2M / main3M 相对 A（+0.055 / +0.045 / +0.063）和 main3M 相对三个 fork 终点（−0.040 ~ −0.065）这几项，幅度都在 0.05 上下，且前者方向与"过期"相反。

**这一读数回答了任务间的连接问题**：任务三（3 个 seed）的终局判定是三分支差异不明显，但撤除/衰减支在尾段胜率上同向略优（+0.054/+0.060，方向一致但被主指标精度吞掉）。若"撤掉略优"是因为 teacher 排序相对变强的策略过期了，一致率应随训练下降；实测不变，说明**终局差异不能用"teacher 偏好过期"解释**——排序信息从头到尾都是那个可靠性水平（约 0.61–0.68），撤掉约束有益的原因更可能是释放优化容量或避免与在线证据冲突（任务三报告第六节的解释框架）。

## 六、与任务二静态版、任务三的衔接

- **静态版（task2_rank_reliability.md）**：一致率 0.614、算法对 0.616；换同族离线续策略 B 不变（配对差 +0.007，CI 跨 0）。本报告把"换续策略"从离线同族扩展到在线全程：t=0 → 主线每 50 万步 → 1M 分叉快照 → 3M 三分支终点，读数同样不变。两个版本合起来：**在测过的所有续策略（离线同族、在线初始化、在线训练 300 万步内的 13 个检查点）上，teacher 排序一致率都在 0.61–0.68 的窄带内，显著高于随机但决策点附近≈抛硬币。**
- **任务三（task3_ranking_loss_fork.md）**：三分支终点放进同一坐标系后，cont3M（保留约束）一致率反而略高（+0.026 vs A，CI 跨 0）、decay3M 略低（−0.006）——任务三的终局判定是三分支差异不明显（640 集配对差 off/decay 相对 continue 为 +0.052/+0.024，seed 间方向不一致），teacher 排序相对撤除/衰减支的可靠性与相对 continue 支没有可测差别。**"撤掉 ranking loss 在尾段指标上略优"不能解释为 teacher 偏好相对变强的策略过期。** Batch2 的主线时间轴让这个排除更硬：主线训练越久，相对 teacher 的配对差越是轻微为正（main3M +0.063），三个 fork 终点相对同训练量的主线 3M 终点反而是 −0.040 ~ −0.065——尾段上那点同向略优与 teacher 排序可靠性的变化无关。
