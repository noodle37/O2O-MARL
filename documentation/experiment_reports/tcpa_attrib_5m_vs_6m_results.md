### 5.1 稳健性（探索性，不参与判读）

bootstrap 区间描述的是**一条轨迹上评估点之间的波动**，不说明效应是不是由少数几个点扛起来的。下面两项补充读数：主窗口内**符号一致率**（有多大比例的评估点与均值同号）与**前后半段是否同号**。

| 探索 fixed_gate − none (broken)         -         -           -           -         -         - |

**噪声地板**两行是安慰剂臂（有同形 hinge、但被保留的「旧动作」是随机合法动作）相对无约束臂的差。安慰剂与真 TCPA 在 hinge 形式、gate、权重上完全一致，所以它的效应就是「只要有这个约束形式就有用」的那部分；`prior` 的效应若明显大于安慰剂，才说明起作用的是**旧动作的内容**而不是约束形式。这一行同时也是单种子单臂差的经验噪声尺度。

### 5.2 操纵检验（broken 干预是否在结果层面生效）

预登记规则里「P1 与 P2 都含 0 → 支持 H1」这一支隐含前提：**队友冻结**这个干预确实在结果层面造出了变化。如果四个约束档位的 `broken − matched` 差全部含 0，说明干预没生效，此时 P1 含 0 只能读作「实验缺少对比」，不能读作 H1 成立。下表就是这项检验。

### 5.3 自相关稳健性（2026-11-12 03:40 补记）

同一批评估点上的配对差不是独立样本：第 k 个评估点的策略与第 k+1 个评估点的策略只差几万个 env 步，差值序列带正自相关。登记用的点自助把相关样本当成独立样本，区间因此偏窄；块自助（moving-block bootstrap，块长 n^(1/3)）按连续块重采样，是同一读数的自相关稳健版本。

| 读数                                n     lag-1 自相关       有效样本量 n_eff         点自助判定         块自助判定 |
|------------|------------|------------|------------|------------|------------|
| P1 交互 prior                      31        +0.013              30.2           含 0           含 0 |
| P2 prior − anchor                31        +0.460              16.2           含 0           含 0 |

**修正方向（只保守、不放宽）**：两个区间一致 → 登记结论不变；不一致 → 登记结论被**撤回**，改记为证据不足。补记只能让判定更难成立，不能把结论改到另一支（H1 或 H2）。

### 5.4 评估节奏与配对一致性检查

**按评估序号配对是否等价于按训练步数配对**，取决于各臂的评估节奏是否一致。下表给出每个臂相邻两次评估之间的 env 步数：

| 臂                 n_eval        首点 t        末点 t          平均步长          最短          最长 |
|------------|------------|------------|------------|------------|------------|------------|
| none_matched         100           0      990539         10108       10003       10224 |
| none_broken          100           0      990769         10110       10003       10239 |
| anchor_matched        35           0      333073         10093       10004       10209 |
| prior_matched        100           0      991570         10118       10004       10234 |
| prior_broken          35           0      333266         10099       10003       10201 |
| fixed_gate_matched      33           0      313044         10098       10001       10210 |

各臂都在**同一个 ~10k 步的评估网格**上，所以第 n 个评估点对应各臂自己训练到 ~10k·n 步的位置——**索引配对 ≈ 步数配对**，与这个臂是几点钟开始跑的无关。同索引上各臂 `t_env` 的实际差别只有几十到几百步（实测 61–282 步，不到一个评估块的 3%），来自各臂回合长度的抖动。

因此「某臂中途崩溃重启」**不会**让索引配对失真：重启后的臂从同一个离线初始化重新开始，第 n 个评估点仍然对应它自己的 ~10k·n 步。真正的后果是（a）这个臂要重跑一遍、队列被拖后；（b）early 窗口测的是重启后那条轨迹，数值会略有不同，但估计的目标量不变；（c）若最终放弃，该臂的 early 窗口点数会变少、统计功效下降——这需要在报告里说明，而不是当成有效读数。

下表是配对一致性的**兜底检查**：若各臂的评估网格不再一致（例如某臂带着不同的评估节奏被重启，或一个日志里混进了两次运行），同索引的 `t_env` 最大差会超过 20000 步，此时读数不可信，**撤回**登记结论、改记证据不足。

| 读数                                 n       t_env 最大差           平均差        最差序号 |
|------------|------------|------------|------------|------------|
| P1                                31             539           263          30 |
| P2                                31             700           276          27 |

**检查结果：通过（配对成立）**。

### 5.5 可检测效应量（探索性，不参与判读）

「CI 含 0」只有在知道**这个实验能看见多小的效应**时才有意义。由 95% CI 的半宽反推标准误（SE = (hi − lo) / 3.92），再按 80% 功效所需的 (1.96 + 0.84)·SE，给出主窗口上各读数**可检测的最小效应**：真实效应若小于这个量级，登记规则读到的就是「含 0」。

| 读数                                 n        点自助 SE        块自助 SE          可检测效应(点)          可检测效应(块) |
|------------|------------|------------|------------|------------|------------|
| P1 交互 prior (matched−broken)      31         0.252         0.279              0.71              0.78 |
| P2 prior − anchor (matched)       31         0.352         0.462              0.99              1.29 |

这个量**不参与判读**，它只是给「含 0」一个参照：读出「含 0」时，应当同时说明这个实验当时看不见多小的效应。块自助那一列一般更大——因为自相关让有效样本量变小，所以同一个规则对自相关稳健性的要求更高。
