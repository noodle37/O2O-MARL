## 三、回报代价

对 P1 对，hinge 约束把在线选择（live argmax，记为 b）推向 teacher 的偏好（a），因此该对实现的回报变化就是 dg = g_a - g_b。候选集对四个策略共用（只用部署策略构建一次），所以四个策略打的是同一批对、同一批状态，差异只来自各自的续跑；E[dg] 因此可以横向比较。

口径提醒：P1 对定义为 (teacher argmax, **部署策略**的 live argmax)。对 ref 该对 100% 涉及它自己的 argmax；对三个分支，同一物理对不一定仍是该分支自己的 argmax（`b_is_live_argmax` 记录了这一点），所以分支列的 E[dg] 应读作“在该分支续跑下、执行 teacher 偏好而非部署策略选择”的效果，而不是“该分支自身 argmax 被改动”的效果。

## 六、两种读法

以下两种读法都基于上面的数字，不再用条件句。

### 支持继续研究 ranking 选择性迁移

- **翻转率在决策相关对上约为一般 hinge 对的 1.8 倍**：P1 0.485–0.517（四策略），P2 0.286（聚类 SE 0.042，与 P1 区间不重叠）。teacher 的偏好恰好在 argmax 真正读取的那一对上更常被真实回报推翻，说明“排序知识”不是一个均匀可靠的资产，而是集中出错的资产。
- **代价不对称且可量化**：翻转时 E[dg] ≈ −1.9 至 −2.3，一致时 E[dg] ≈ +1.3 至 +1.9。跟随一个被推翻的偏好，平均要付出约 2.2 的折扣回报，而猜对只赚回约 1.5；单对可实现损失中位数 0.48–0.69，均值 1.9–2.3。
- **决策相关对的期望效果为负**：E[dg] 从 ref 的 −0.637 到 off 的 −0.182 全为负，聚类 SE 0.13–0.23。排序约束在单个决策上平均是有害的，且有害幅度（0.2–0.6）与 fork 实验里“撤除约束无显著改善”的读数（±0.05 胜率）方向一致、量级可对照——这正是选择性迁移要处理的误差源，而不是可以忽略的噪声。
- **失配可被部署时可观测信号部分预测**：只用在线可观测特征（不含 ΔG），按轨迹分组 4 折，AUC 0.616（logistic 与 gbdt 一致）。预测力主要来自 `enemies`、`t`、`allies`、`abs_q_gap_live`——即战斗阶段与敌我存活结构，这些在部署时都可直接读取。说明“哪些 teacher 偏好不可信”不是纯反事实的，gate 在原理上有可行性。

### 反驳继续研究 ranking 选择性迁移

- **AUC 0.616 的信息量很薄**：正例率 0.500 的平衡标签下，0.616 对应的约化对数损失改进有限；前四位特征全是粗粒度状态量（存活数、时间步），没有一个直接度量“该对的 teacher 偏好可信度”。也就是说可预测的部分主要是“战斗到了哪个阶段”，而不是“这一对排序对不对”——用阶段信息做 gate，等价于一个按战斗进度开关排序损失的调度器，而 TDR 的 η 衰减已经在做这件事，且 TDR 是唯一显著的组。
- **约束越弱、期望损失越小，单调可读**：E[dg] 从 ref/continue 的 −0.63 单调升到 off 的 −0.18，翻转率同步从 0.517/0.511 降到 0.485。teacher 偏见的伤害随约束减弱而衰减，意味着“选择性 gate”要挽回的收益上界本身就在收缩；把约束整体去掉已经拿到了大部分（off 的期望损失 0.939 对比 ref 的 1.187），剩下的 0.25 不值得一套 gate 的复杂度。
- **翻转集中在无关紧要的区间**：己方存活 ≤2 时翻转率只有 0.254（n=272，区间 [0.145, 0.362]），而这些恰是战斗尾声、单步回报影响被折扣放大的决策；存活 5 的满编期翻转率 0.553 但对应的是探索/接战前的动作，实际 argmax 差异的回报后果小（P2 一般对翻转率仅 0.286 且 |dg| 未显示系统性放大）。高翻转率与高代价并不同时出现。
- **本测量只覆盖 seed 1 的一个 fork 家族**：64 个环境种子提供了轨迹级聚类，但训练种子只有 1 个，聚类 SE 反映的是环境方差，不含训练种子方差。fork 实验 3 个种子的 off−continue 差已在 ±0.053 不确定度内为零。在本报告的净效应同样只有 −0.2 至 −0.6（每对）的情况下，ranking 选择性迁移缺少一个已被证实存在、且值得用 gate 去追逐的机制目标。

### 两种读法的分界

分界不在翻转率（0.50 对 0.29 已经很明确），而在**可门控性**：AUC 0.616 与阶段/存活特征的主导，决定了“选择性 gate”要么退化成一个 η 调度器（此时 TDR 已经赢了），要么需要 teacher 偏好可信度的直接度量（当前特征集里没有）。要继续这条线，下一步不是扩大翻转统计，而是补一个直接度量“该对可信度”的在线信号。

## 七、口径与限制

- 分支回放的真 ΔG 只作标签；第五节的预测特征全部在线可观测，未使用 ΔG、G 或任何反事实量。
- P1 对由部署策略定义；分支列的 E[dg] 应读作“在该分支续跑下执行 teacher 偏好”的效果（见第三节口径提醒）。
- P2 对按构造不含执行动作（抽样时排除了 argmax 对），其“涉及执行动作 = 0”是构造结果。
- 环境种子 64 个提供轨迹级聚类；训练种子 1 个，聚类 SE 不含训练种子方差。
- 候选对总体为 UOT hinge 自己的候选集（K=8, Hamming ≤ 2），不等于全合法联合动作空间；`exec_in_cand=1051/1656`，即约 36% 的决策步执行动作不在 hinge 候选集内，这些步的 argmax 冲突未被本测量覆盖。
